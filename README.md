# Brick Breaker Game — Lab 4 VibeCoding

This is the completed version of the assigned Pygame Brick Breaker project.

## Setup

Python 3.10+ is recommended.

```bash
pip install -r requirements.txt
python main.py
```

## Controls

- `Left Arrow` / `A` — move paddle left
- `Right Arrow` / `D` — move paddle right
- `Q` / `Esc` — exit
- After winning/losing:
  - `1` — Easy
  - `2` — Medium
  - `3` — Hard
  - `Q` / `Esc` — exit

## Completed Lab Tasks

1. **Refined collision detection**
   - Uses the ball's previous and current rectangle to determine whether a paddle/brick was hit from the left, right, top, or bottom.
   - Side hits reverse `vx`; top/bottom hits reverse `vy`.
   - Paddle hits also vary the outgoing angle based on where the ball strikes the paddle.

2. **Game-over / win screen**
   - Displays WIN or GAME OVER.
   - Displays final score.
   - Waits for keyboard input rather than printing only to the console.

3. **Replay + difficulty**
   - After the end screen, choose Easy, Medium, or Hard.
   - Difficulty changes ball speed, paddle width, and paddle speed.

4. **Sound feedback**
   - Procedural sound effects are generated by Pygame.
   - No external audio files are required.
   - Sounds are provided for wall/paddle hits, brick breaks, and the end of the game.
